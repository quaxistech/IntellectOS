# IntellectOS — продуктовая конституция

**Статус:** утверждённое целевое направление; реализация отдельных пунктов проверяется отдельно.

## 1. Миссия

Построить собственную независимую, эффективную и интеллектуальную операционную систему, которой пользователь доверяет владение компьютером. ОС должна загружаться непосредственно на аппаратуре, работать без Windows/Linux/GRUB как скрытого runtime, управлять памятью, устройствами, приложениями и файлами, и оставаться полезной даже без ИИ и интернета. ИИ — дополнительный контролируемый слой автоматизации и разработки, не часть CPU-пути и не источник полномочий.

**Пять компонентов экосистемы:** IntellectOS (ядро, сервисы, редакции), IntellectFS (собственная ФС), IVX (нативная верифицируемая программа), Vibelang (`.vibe`, строгий компилируемый язык), интеллектуальный компилятор (детерминированный базовый backend + опциональные AI-кандидаты). Их интерфейсы независимы и версионируются раздельно.

## 2. Неизменяемые принципы

1. **Нативность.** Реальное железо — цель. Эмуляция/QEMU — стенд испытаний, не конечная среда. Хост Ubuntu 24.04 — инструмент разработчика, не зависимость установленной ОС.
2. **Аппаратная универсальность по контрактам.** Никакого hard-code Lenovo, конкретного разрешения экрана, `1920×1080`, одного GPU, SATA-контроллера или одного протокола ввода в продуктовой логике. Вместо обещания «любой ПК» — детектируемые capability, явно поддерживаемые наборы и fallback.
3. **Console-first, GUI позже.** Первая полноценная система — терминальная, удобная и для персонального, и для серверного использования. Серверная/headless конфигурация работает без монитора. Графический установщик допускается как удобный preboot UI без требования полноценного GUI ядра. Графическая редакция развивается на общем ядре и ABI.
4. **Безопасная правильность выше красивого успеха.** Подписание файла не заменяет политику полномочий, дизайн IntellectFS не заменяет crash-proof writer, тест — не гарантия совместимости, недоступное устройство → явное сообщение/отказ.
5. **Пользователь владеет конфигурацией.** `root` для первой редакции; пароль опциональный, разрешён пустой, короткий, произвольный до разумного максимума. Нет принудительной длины 12+ символов. При непустом пароле — корректный KDF/проверка; пустой — явное состояние. Пользователю сообщается риск, но автономный локальный стенд не блокируется.
6. **Продукт должен быть приятным.** Единый фирменный знак, аккуратная адаптивная загрузка, читаемый терминал, удобная установка, будущий звук по желанию, отсутствие навязанных анимаций и жёстко заданных разрешений. Возможность отключения звука и reduced-motion.
7. **Один source of truth.** Репозиторий `/home/quaxis/IntellectOS`, GitHub `quaxistech/IntellectOS`, ветка `main`; `build/` — создаваемые артефакты. Без дополнительного проекта `IntellectOS-debug`, множества конфликтующих патчей, фальшивых миграций и версий V2 до первичной заморозки V1.
8. **Проверяемость.** Воспроизводимая сборка, самостоятельный валидатор, host+QEMU+physical acceptance, диагностика с указанием причины и предложенного восстановления.

## 3. Продуктовые профили — одно ядро

| Редакция | Базовые функции | Дополнительные функции |
|---|---|---|
| **Base/Recovery** | kernel, memory isolation, native block, fsck, VFS, signed IVX loader, init, terminal, policy, logs | аварийное восстановление, offline |
| **Terminal Edition** | Base + полноценный интерактивный терминал, login/пользователи, инструментирование, пакеты | локальное и серийное управление |
| **Server Edition** | Base + supervisor служб, сеть, безопасный remote TTY, хранение/обновления | daemon/automations, headless, optional AI |
| **Desktop/Graphical Edition** | тот же kernel, ABI, VFS и IVX, графический стек, HID, compositor, shell | GUI приложения, AI-фронтенд, темы |
| **Developer Edition** | Vibelang toolchain, native IVX/IVO/IVL utilities | AI-assisted optimizer, профилировщик |

Редакции — наборы служб/пакетов, не независимо расходящиеся ОС. Их сервисы могут сосуществовать. Desktop не блокирует Server и наоборот. В будущих архитектурах (AArch64 и др.) — отдельный порт под другой ISA/boot ABI, а не предположение, что один x86-64 бинарник запускается везде.

## 4. UX пользовательской установки

На USB: красивое адаптивное меню с двумя простыми действиями `LIVE TERMINAL` и `INSTALL`. В установщике: язык/клавиатура (по поддержке), локальный или UTC часовой пояс, обнаруженные физические диски с размером/моделью, безопасный выбор разделов, предупреждение об уничтожении, предложение форматировать IntellectFS, опциональный пароль root, проверка всех файлов и bootloader, финальное извлечение USB и boot. Функции `создать/удалить/изменить раздел` относятся к позднему полноценному partition editor, но не должны подменяться фразой «всё умеет» при простом full-disk wipe.

При каждой установке нужно сохранять возможность диагностики и восстановления, при возможности — резервные копии таблиц разделов. Запись только в **явно подтверждённый** целевой диск; нельзя выбирать системный диск хоста по совпадению имени.

## 5. Отменённые соблазны

- Не делать обязательный Linux-host, GRUB, скриптовую VM или непрозрачное облачное ядро.
- Не считать `IVX` с developer BLAKE3 pin универсальным загрузчиком произвольных signed apps.
- Не считать частичный boot profile IntellectFS заменой всей CoW RW + recovery архитектуры.
- Не выдавать QEMU+один Lenovo за «любой компьютер».
- Не позволять AI без авторизации править ядро, boot policy, firmware и документы спецификаций.
- Не требовать минимальную длину root-пароля; не вписывать секреты в репозиторий.
- Не превращать опциональный звук/эффекты в причину неудачной загрузки.

## 6. Определение готовности

**Terminal Alpha** = независимая загрузка установленного HDD, действительный loader файловой программы, работающий login policy, fail-closed драйверы, воспроизводимый QEMU тест, один физический end-to-end. **Terminal Beta** = поддержка современных контроллеров, USB-HID/TTY, полномасштабный безопасный installer, recovery и файловая RW-долговечность. **Desktop Alpha** отдельно требует графический compositor/input/services, не меняя базовых ABI. **Stable** — независимый аудит, матрица оборудования, отрицательные тесты, подписи, обновления и восстановление.
