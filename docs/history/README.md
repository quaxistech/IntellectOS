# Исторические вехи и прежние инструкции — не действующее ТЗ

Здесь сохраняются **без изменений** локальные инструкции и результаты BIOS/UEFI, Memory Core M1/M2/M3, C1, H1/H2, S0, L1, B1, U1, I2, старые статусные отчёты и любые дополнительные прежние документы. Они оставлены как provenance, не как перечень текущих функций или команд для повторной установки старых ZIP-патчей. Актуальные команды, продуктовые требования и критерии испытаний — в новых документах.
